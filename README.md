# crystal-glass-EBSD-supplementary
Matlab scripts using MTEX toolbox v. 5.11.2 (https://mtex-toolbox.github.io/) to assess the effect of different EBSD processing parameters on microstructural quantification of crystal-glass assembages from EBSD data. Also contains raw data and pre-generated Matlab variables (.m files) of all processing scripts so results can be immediately plotted.
